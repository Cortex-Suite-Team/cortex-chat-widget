Mock Example

Cortex Chat Widget

This page mounts the real widget bundle from the GitHub-hosted repository build and wires it to a mock client instead of a live Runtime.

No real API key, Control Plane, Runtime, or Digital Worker is required. Text replies, typing state, and attachment uploads are simulated in-browser.

What to try

  • Send a message and watch the partial response stream into a final answer.
  • Attach one file to exercise the mocked uploadAttachment() path.
  • Refresh the page and rerun the demo without any backend setup.
